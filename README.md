# سجل الصلاة — Prayer Sheet

تطبيق موبايل بسيط (Flutter) لتسجيل الصلوات الخمس كل يوم، ومراجعة سجل الأيام السابقة.
كل البيانات محفوظة على الجهاز نفسه — من غير إنترنت ولا حساب ولا أي بيانات بتطلع برّه الموبايل.

A simple Flutter app for logging the five daily prayers and reviewing past days.
Everything is stored on-device — no account, no network, nothing leaves the phone.

## الفكرة

- تفتح التطبيق تلاقي صلوات النهاردة الخمسة قدامك.
- تدوس على الصلاة اللي صليتها، تبقى ✓ خضرا ومعاها وقت التسجيل.
- تفتح التطبيق تاني في أي وقت وتكمّل باقي الصلوات.
- زرار **سجل الأيام** بيوريك كل الأيام اللي فاتت وكام صلاة اتسجلت في كل يوم.
- نسيت تسجّل صلاة إمبارح؟ تقدر تدوس على اليوم في السجل وتعدّله.

## المميزات

| | |
|---|---|
| شاشة اليوم | الصلوات الخمسة + دائرة تقدّم (مثلاً 3/5) ووقت تسجيل كل صلاة |
| شريط الأسبوع | آخر ٧ أيام في سطر واحد، تدوس على أي يوم فيهم تعدّله |
| سجل الأيام | كل الأيام المسجّلة من الأحدث للأقدم، وأي صلوات ناقصة فيها |
| إحصائيات | عدد الأيام الكاملة، إجمالي الصلوات، وسلسلة الأيام المتتالية |
| تسجيل الكل | زرار واحد يسجّل باقي صلوات اليوم |
| واجهة عربية | الواجهة كلها عربي ومن اليمين لليسار، ومعاها وضع ليلي |

## بنية المشروع

│   └── prayer_store.dart        الحفظ والقراءة والإحصائيات
├── screens/
│   ├── home_screen.dart         شاشة اليوم
│   └── history_screen.dart      سجل الأيام

    ├── prayer_tile.dart         صف الصلاة الواحدة
    ├── today_header.dart        كارت اليوم ودائرة التقدّم
    ├── day_dots.dart            النقط الخمسة لكل يوم في السجل

## كيف البيانات متخزنة

كل السجل بيتحفظ في `shared_preferences` تحت مفتاح واحد (`prayer_records_v1`) على شكل JSON:

```json
{
  "2026-09-11": { "fajr": "2026-09-11T05:12:00.000", "dhuhr": "2026-09-11T13:40:00.000" }
}
```

اليوم اللي مفيهوش أي صلاة مسجّلة مش بيتخزن أصلاً، فسنة كاملة من الاستخدام حجمها كام كيلوبايت بس.
